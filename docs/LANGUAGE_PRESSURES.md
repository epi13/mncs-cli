# MNCS language pressure ledger

For each finding record the CLI workload, current behavior, desired behavior, reproducer, owner, workaround and closure test.

## Initial pressure targets

- declarative typed command schemas
- compile-time metadata/generation for help and completion
- named/default arguments and ergonomic option definitions
- enums, optionals and validation errors
- Unicode argv and terminal text
- stdin/stdout/stderr abstractions
- environment and process effects
- terminal detection/capability APIs
- iterators/streams for large input
- cancellation/signals and exit semantics
- snapshots and deterministic command tests
- high-quality compiler diagnostics for routine CLI mistakes
